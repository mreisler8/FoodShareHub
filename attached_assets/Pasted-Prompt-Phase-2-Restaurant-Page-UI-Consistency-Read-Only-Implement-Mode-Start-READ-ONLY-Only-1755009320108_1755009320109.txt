2) Remove duplicate rating UI & duplicate fetches

Delete/disable any secondary “Your Rating” indicators/cards/badges.

3) Unify Circle Score usage
All Circle Score placements must read the same query:

useQuery(['circleScore', restaurantId], GET /api/restaurant/:restaurantId/circle-score)

Replace any legacy keys/endpoints (e.g., ['/api/circle-score'], ['circle-score-data']).

If ratingsCount < 2 (or the returned confidence is “low”), show the low-data state consistently instead of contradictory numbers.

4) Lists & Similar: no mocks, real data only
Remove or production-gate any mock arrays (lists/posts/similar).

Wire both to the standardized hook keys above.

If no results, show empty states (don’t fabricate content).
