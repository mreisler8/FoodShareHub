2) Google Places: async + timeout + circuit breaker
New file: server/services/placesService.ts

async searchPlaces(query, lat?, lng?) and async getPlaceDetails(placeId)

Wrap the underlying Places calls with:

Timeout: Promise.race([placesCall, timeout(PLACES_TIMEOUT_MS)])

Circuit breaker: count consecutive failures; on threshold, short-circuit for PLACES_CIRCUIT_COOLDOWN_S (return null quickly).

Redis cache: cache hits and empties (TTL = PLACES_CACHE_TTL_S).

Never block DB results on Places. If timeout/breaker triggers, return null (we’ll merge DB-first).

Merge rule: DB results are primary; append unique Places hits (dedupe by googlePlaceId or normalized name+geo).

3) Route integration (non-blocking)
Update restaurant search route (e.g., server/routes/search.ts or server/routes/restaurants.ts):

Compute cache key; on hit → return.

In miss path, run DB search and Places in parallel:

ts
Copy
Edit
const dbPromise = searchRestaurantsInDB(q, lat, lng, filters);
const placesPromise = ENABLE_PLACES
  ? Promise.race([
      placesService.searchPlaces(q, lat, lng),
      timeout(PLACES_TIMEOUT_MS)
    ]).catch(() => null)
  : Promise.resolve(null);

const [dbRes, placesRes] = await Promise.allSettled([dbPromise, placesPromise]);
const dbResults = dbRes.status === 'fulfilled' ? dbRes.value : [];
const placesResults = placesRes.status === 'fulfilled' ? (placesRes.value || []) : [];

const merged = mergeRestaurants(dbResults, placesResults); // dedupe + rank
await cache.setCached(cacheKey, merged, SEARCH_CACHE_TTL_S);
return res.json({ results: merged, total: merged.length, entity: 'restaurant', meta: { page: 1, hasMore: false } });
If Places is slow or fails → DB results still return fast.
