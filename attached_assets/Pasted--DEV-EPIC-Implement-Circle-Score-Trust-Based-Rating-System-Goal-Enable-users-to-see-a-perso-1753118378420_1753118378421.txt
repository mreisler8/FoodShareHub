🧭 DEV EPIC: Implement Circle Score — Trust-Based Rating System
🎯 Goal:
Enable users to see a personalized Circle Score for each restaurant based on meaningful actions from people they trust. This replaces anonymous public review scores with high-signal data from Circles and followed users—surfaced directly in search results and restaurant pages.

🔨 BACKEND – Scoring Engine & API
1. Circle Score Calculation Logic
File: lib/circleScore.ts

Inputs: restaurantId, requestingUserId

Process:

Fetch relevant Quick Ratings shared by trusted users (Circles and follows)

Fetch Lists shared in Circles where the restaurant is ranked

Optionally fetch Reactions and Saves (if available now or later)

Apply scoring formula:

ts
Copy
Edit
rawScore = (
  quickRatingValue × 3 +
  listPlacementWeight +
  reactions × 2 +
  saves × 1
) × recencyDecay × confidenceModifier
Normalize to a 0–100 score

Return: { score, confidenceLevel, contributors[] }

2. API Endpoint
Route: GET /api/circle-score/:restaurantId
Output:

  ]

Authenticated only

Only includes shared data from trusted sources

📦 BONUS – Reusability & Optimization
Move shared logic to CircleScoreCard.tsx and useCircleScore.ts

Debounce or batch fetches where possible

Use react-query to avoid redundant fetches

🔒 NFRs & Data Integrity
Don’t show scores if no valid data (graceful fallback)

Must be Circle-based only (no global averages)

Performance: indexed queries only; avoid N+1 issues

Privacy: no exposure of hidden/private content

Circle integrity: verify circle_member status before exposing data

✅ Acceptance Criteria
Feature	Requirement
