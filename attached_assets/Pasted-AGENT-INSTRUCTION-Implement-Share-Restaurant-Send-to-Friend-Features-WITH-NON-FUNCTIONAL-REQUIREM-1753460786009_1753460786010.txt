BACKEND IMPLEMENTATION
1. Database Schema
Create shared_recommendations table with these fields:

id (primary key)
sender_id (foreign key to users, indexed)
receiver_id (foreign key to users, nullable for external shares, indexed)
entity_type (enum: "restaurant" | "list")
entity_id (string, indexed)
share_type (enum: "internal" | "external")
message (text, optional, 140 char limit)
expires_at (timestamp, for external links)
read (boolean, default false)
click_count (integer, default 0)
created_at (timestamp, indexed)
Required Indexes:

CREATE INDEX idx_shared_recommendations_receiver ON shared_recommendations(receiver_id, read, created_at);
CREATE INDEX idx_shared_recommendations_sender ON shared_recommendations(sender_id, created_at);
CREATE INDEX idx_shared_recommendations_entity ON shared_recommendations(entity_type, entity_id);
CREATE INDEX idx_shared_recommendations_expires ON shared_recommendations(expires_at) WHERE expires_at IS NOT NULL;
2. API Endpoints
Implement these routes in server/routes/:

POST /api/recommendations/share-internal
- Rate Limited: 10 requests per hour per user
- Body: { receiverId, entityType, entityId, message? }
- Validates sender follows receiver or shares circle membership
- Creates internal share record
- Returns success/error status
- Response time SLA: < 2 seconds
GET /api/recommendations/received
- Paginated: 20 items max per page
- Returns paginated list of items shared with authenticated user
- Include sender info, entity details, read status
- Response time SLA: < 1 second
PATCH /api/recommendations/:id/mark-read
- Marks specific share as read
- Only allows user to mark their own received shares
- Response time SLA: < 500ms
POST /api/share/generate-public-link
- Rate Limited: 20 requests per hour per user
- Body: { entityType, entityId }
- Generates secure short URL with 7-day expiration
- Returns shareable link
- Respects privacy settings (public lists/restaurants only)
- Response time SLA: < 1 second
