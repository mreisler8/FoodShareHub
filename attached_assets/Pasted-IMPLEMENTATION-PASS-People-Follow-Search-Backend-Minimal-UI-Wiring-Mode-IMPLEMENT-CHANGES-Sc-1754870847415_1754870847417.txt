Ranking logic (MVP):

mutualsCount DESC (people you share the most connections with)

text relevance to q (if q provided; username/name/bio)

recency/popularity proxy (followersCount DESC as a simple tie-breaker)

Mutuals definition (MVP, simple & fast):

mutualsCount = count of users that currentUser follows who also follow candidate user
(intersection on follows table).

If a simpler join is already available (e.g., mutual follow), use that; just document which one.

Performance requirements:

Use existing GIN / trigram indexes on users.username, users.name and any text fields used.
