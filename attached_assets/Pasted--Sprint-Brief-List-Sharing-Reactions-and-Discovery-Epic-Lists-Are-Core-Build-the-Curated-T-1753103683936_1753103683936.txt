🔐 Implementation Requirements
Only list creators can edit or delete their lists

Only published lists can be reacted to or saved

All feed views must respect visibility

Profile setting isPublic gates whether “Public Feed” option is allowed

Must not impact feed scroll performance — paginate list data & counts

🧪 Edge Cases
Scenario	Behavior
No share destination selected	Block publish with “Choose where to share” error
Try to react as logged-out user	Prompt login modal
Try to share to Circle but user has none	Show prompt: “Join a Circle to share there”
List is edited and shared again	Update feed data immediately
User saves same list twice	Toggle, don’t duplicate
