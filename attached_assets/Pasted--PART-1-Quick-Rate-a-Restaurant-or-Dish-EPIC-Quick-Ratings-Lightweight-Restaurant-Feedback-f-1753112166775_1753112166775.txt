✅ PART 1: Quick Rate a Restaurant or Dish
🧩 EPIC: Quick Ratings – Lightweight Restaurant Feedback for Everyone
🎯 Objective
Let users give a quick 1–5 star (or emoji) rating to a restaurant or dish, optionally add a note or tag, and decide if they want to share it with a Circle — all without creating a full list or post.

👤 USER STORY 1: Quick Rate a Restaurant
✅ UI Component: QuickRatingModal.tsx
Element	Behavior
⭐ Star rating (1–5) or emoji scale	Tap = select rating
📝 Optional 140-char note	Textarea with char counter
🏷 Optional tags	Chips: “Perfect for brunch”, “Hidden Gem”, “Too Loud”
🔘 Toggle: “Share with my Circle”	Optional – default OFF
✅ Submit button	One tap; saves and closes modal

After Submit → toast:

“Thanks! Your rating has been saved.”

🧱 ENTRY POINT
Location	Trigger
RestaurantCard.tsx	Add ⭐ icon or “Rate” button
SearchResultsItem.tsx	Show small “Rate” button right-aligned
Optional: RestaurantView.tsx	Show inline star rating + Edit option if rated

🧪 UX Details
Modal/Drawer opens lightweight form (max-w-sm, p-4, space-y-4)

Confirm button is disabled until rating selected

Use expressive icons/emojis to reduce visual friction

Respect motion: slight animation when selecting stars

Allow only one rating per user per restaurant

Store as a standalone table for analytics & Circle Score input

👤 USER STORY 2: View or Update My Rating
If a user has rated this restaurant:

Show their rating inline in RestaurantCard or RestaurantView

Allow them to tap “Edit Rating” → opens QuickRatingModal pre-filled

Future: “Your Ratings” tab on profile

👤 USER STORY 3: Feed Into Circle Score (System Logic)
✅ Just store the data for now

System will later query all ratings where shared_with_circle = true

No UI implication yet beyond backend persistence
