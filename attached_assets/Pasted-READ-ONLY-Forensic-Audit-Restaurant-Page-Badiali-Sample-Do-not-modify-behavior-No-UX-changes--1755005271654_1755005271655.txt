What to Prove / Questions to Answer
Identity: Is every widget using the same restaurantId? If any use placeId, list file + line.

Contamination: Is any widget still showing a rating fetched by placeId where the resolved restaurantId differs?

Save failure: For “Update Rating,” what endpoint and body are used? If the server rejects, what’s the exact status & message?

Circle Score: Do the top tile and “Your Circle’s Take” consume different endpoints/keys? If yes, list both and show their raw responses.

Featured Lists: What’s the data source? If it’s mock/demo, call it out with the exact import path.

Duped Rating UI: How many distinct places render “your rating”? List component names and file paths.
