3 Safe-Area & Stacking
Header height: 56px.

Add pt-[56px] (or pt-safe-header) to each page container so content
never scrolls under header.

Confirm FAB and BottomNav still respect safe-area.

4 Accessibility & Focus
Back button ≥ 44 px touch area, focus ring as in sample.

Logo link has aria-label="Circles Home" and sr-only span for screen
readers.

Page title uses semantic <h1> but is visually centered.
