Audit Prompt — Restaurant Page Data Integrity & Consistency (Read-Only + Debug Mode)
Mode: Audit & Instrumentation only.
Do NOT change product behavior for normal users.
Allow only: server logging, debug-only UI (behind ?debug=true), sampling scripts, and reports.

Objectives
Prove or disprove any cross-restaurant contamination of ratings.

Explain Circle Score inconsistency (e.g., 89 vs 0 on the same page).

Detect redundant “my rating” render paths that cause duplicate fetches/race conditions.

Verify search → detail handoff (Google Place ID → canonical restaurantId) is correct for all restaurants, not just one.

Produce a clear, actionable report with file paths, lines, and minimal code changes needed to fix.

A2. Mismatch sentinels (no throw, just log)
If a rating payload references a different restaurantId than the request → log note:"RATINGS_MISMATCH".

If two different circle score values are calculated/returned for the same restaurantId during the same request → log note:"CIRCLE_SCORE_INCONSISTENT".

Do NOT change responses; this is observability.
