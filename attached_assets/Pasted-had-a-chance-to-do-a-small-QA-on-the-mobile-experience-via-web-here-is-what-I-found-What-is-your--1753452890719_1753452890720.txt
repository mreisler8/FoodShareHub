Looking at your QA findings, I can see several critical mobile experience issues that need systematic remediation. Here's my assessment and recommended approach:

Root Cause Analysis
1. Mobile UI Overlapping & Scrolling Issues

Root Cause: The app has conflicting navigation layers (desktop sidebar + mobile navigation) and improper viewport/safe area handling
Evidence: From the codebase, I see both MobileNavigation and DesktopSidebar components being rendered simultaneously, plus missing proper mobile viewport meta tags and safe area CSS
2. Authorization Errors

Root Cause: Session/auth middleware not properly handling mobile browser sessions or CORS issues
Impact: This affects follow functionality and other authenticated actions
3. Quick Rate Modal Tag Overload

Root Cause: The SmartTagInput component is showing too many suggestions without proper filtering or limits
Evidence: No visible tag filtering logic in QuickRateModal.tsx
4. Restaurant Page Actions Failing

Root Cause: Multiple issues - broken API endpoints, React hook violations causing state corruption, and mobile touch event handling problems
Systematic Remediation Plan
Phase 1: Critical Mobile Infrastructure Fixes
1. Fix Navigation Layer Conflicts

Implement proper responsive navigation that only shows one navigation system at a time
Fix the CSS classes in index.css - the .nav-mobile and .nav-desktop classes need proper media query isolation
Add proper viewport meta tags and safe area CSS variables
2. Resolve Session/Auth Issues

Debug the session middleware in server routes to ensure mobile browsers maintain proper authentication
Check CORS settings for mobile web browsers
Verify the auth context is properly propagating to all mobile components
Phase 2: Component-Level Fixes
3. Quick Rate Modal Optimization

Limit tag suggestions in SmartTagInput to max 8-10 most relevant tags
Implement better tag filtering based on restaurant type/cuisine
Add mobile-optimized tag selection UI with larger touch targets
4. Restaurant Page Action Bar

Fix the React hook violations in useRestaurantRatingState that are breaking state management
Implement proper error handling and loading states for all action buttons
Ensure RestaurantActionBar properly handles both mobile and desktop variants
Phase 3: Search & Sharing Integration
5. Share List Search Integration

Update ShareListModal to use the unified search service from searchService.ts
Implement the restaurant search functionality in list sharing workflows
Ensure mobile-optimized search results display
6. Add to List Functionality

Fix the API integration in RestaurantAddToListModal component
Ensure proper restaurant ID handling (database vs Google Place ID)
Add proper mobile touch event handling
Priority Implementation Order
Navigation & Scrolling (Highest Priority) - This affects every page
Authentication (High Priority) - Blocks core functionality
Restaurant Page Actions (Medium Priority) - Core user journey
Search Integration (Medium Priority) - Feature completeness
UI Polish (Lower Priority) - Tag optimization, mobile refinements
Development Approach
Start with fixing the CSS foundation and navigation conflicts
Move to backend auth/session debugging
Then tackle component-level React issues
Finally integrate search services properly
