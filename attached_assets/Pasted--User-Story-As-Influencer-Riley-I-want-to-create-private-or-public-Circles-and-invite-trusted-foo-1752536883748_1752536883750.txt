✅ User Story:
As Influencer Riley, I want to create private or public Circles and invite trusted foodies, so we can share curated lists in a group space and discover from each other.

🎯 Acceptance Criteria:
🛠️ Circle Management
User can create a new Circle:

Name (required)

Optional: description, cover image

Visibility setting: Private (invite-only) or Public (anyone can join)

User can invite members via:

Username (auto-suggest)

Copyable invite link or QR code

Creator becomes the admin with ability to:

Approve join requests (if private)

Remove members

📥 Sharing to a Circle
When creating or editing a list, user can choose:

Profile (followers)

Public feed

One of their Circles

Lists shared to Circles appear in:

Circle feed (e.g., “Shared in Toronto Bites”)

Homepage feed for Circle members

🔒 Permissions
Only members can view private Circle content

Public Circles are discoverable in search/explore

Optional: Circles display member count + creator

🧠 Edge Cases / Unknowns
Can users belong to unlimited Circles?

Can a list be shared in multiple Circles?

Are Circles ranked/sorted (e.g., most active first)?

📌 Priority: ⭐⭐ High
Circles are core to the “trusted reco” loop—enabling a social layer that’s private, curated, and sticky.

Scrum- 
 Sprint 1: Circle Creation & List Sharing MVP
🎯 Sprint Goal
Allow users to create a Circle, invite members, and share lists to Circles, establishing the core group recommendation loop.

📦 Stories & Points
#	Story Slice	Description	Points
1	Circle Creation UI	Form to create Circle with name, visibility, description, cover image	3
2	Invite by Username	Autosuggest usernames to invite to Circle	2
3	Copyable Invite Link	Generate shareable invite link (QR code optional)	1
4	Share List to Circle	Share to Circle from list creation/edit screen	3
5	Circle Feed View	Show lists shared to a Circle on its own page	3
6	Circle Permissions (Basic)	Only members can view private Circle content	1

Total: 13 points

✅ Sprint 2: Member Management & Permissions
🎯 Sprint Goal
Build admin tools and access logic to manage Circle members and ensure privacy controls are respected.

📦 Stories & Points
#	Story Slice	Description	Points
1	Admin: Approve Join Requests	If private, show and manage incoming join requests	3
2	Admin: Remove Members	Allow Circle creator to remove members from the group	2
3	Circle Member Permissions	Only members can post or share lists to a Circle	2
4	Join via Invite Link	Accepting link request adds user to Circle if public, or requests if private	2
5	Circle Metadata	Display member count, creator, and visibility on Circle page	2
6	Error & Access Handling	Gracefully handle unauthorized access or removed users	2

Total: 13 points

✅ Sprint 3: Circle Discovery & Social Growth
🎯 Sprint Goal
Make public Circles discoverable and encourage growth through social interactions and tagging.

📦 Stories & Points
#	Story Slice	Description	Points
1	Circle Discovery UI	Add explore page section for public Circles	3
2	Searchable Circles	Allow users to search for Circles by name or tag	2
3	Follow or Join Circle Button	One-tap join (if public) or request (if private)	2
4	Suggested Circles Feed	Show relevant Circles on homepage or onboarding flow	2
5	Circle Tag System	Allow creators to tag Circles for categorization (e.g., “Toronto”, “Sushi”)	2
