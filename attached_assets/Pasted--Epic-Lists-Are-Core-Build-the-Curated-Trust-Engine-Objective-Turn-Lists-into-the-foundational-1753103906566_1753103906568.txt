🧩 Epic: Lists Are Core – Build the Curated Trust Engine
Objective: Turn Lists into the foundational content experience of Circles—something users love creating, exploring, and interacting with. Lists should be expressive, easy to start, and socially meaningful across profiles, Circles, and feeds.

✅ User Story 1: Create a Flexible, Expressive List
As Tracker Taylor, I want to create a list of restaurants and/or specific dishes, so I can organize and share my food experiences in a structured, curated format.

Acceptance Criteria:
User can:

Title the list (required)

Add description, cover image (optional)

Choose “Ranked” or “Unranked” toggle

Each list item supports:

 Restaurant or Dish mode

 Optional image, notes, tags, city

 Reorder (if ranked)

List can be saved as draft or published

✅ User Story 2: Share a List to Circles, Profile, or Public
As Influencer Riley, I want to choose where my list gets shared—Profile, Circle, or Public Feed—so that I can control who sees it.

Acceptance Criteria:
Share destination selection is required before publishing

 Profile (follower-only)

 Circle (dropdown select)

 Public Feed (if profile is public)

Confirmation modal appears on publish

Shared list shows a badge/tag in feed (e.g., “Shared to: @torontofoodies”)

✅ User Story 3: Edit, Unpublish, or Re-share a List
As Tracker Taylor, I want to be able to edit my list or unpublish it, so I can update my recommendations or change my mind.

Acceptance Criteria:
Creator can:

Edit title, description, items, order, tags

Change share destination

Unpublish/delete the list

Edits sync across Profile and feeds

✅ User Story 4: Save and React to Lists
As Seeker Sam, I want to save or react to a list, so I can remember it for later and engage with the creator.

Acceptance Criteria:
Every list card has:

 Save icon (adds to “Saved Lists” in profile)

 ❤️ or 👍 reaction (tallied per list)

Reaction is lightweight (1-tap)

User can unsave or remove reaction

✅ User Story 5: Discover Lists via Feeds and Profiles
As Explorer Alex, I want to browse great lists shared by others, so I can find new restaurants or ideas from people I trust.

Acceptance Criteria:
Lists appear in:

 Homepage feed (if Public)

 Circle feed (if shared to Circle)

 Creator’s profile

 “Saved Lists” in user profile

Each list shows:

Creator name

Share destination

Save count

List tags (tap to filter)

🛠 Implementation Requirements
✅ Fully reuse homepage layout styles (cards, buttons, spacing)

✅ Reuse search backend logic for adding restaurant/dish

✅ Mobile-first, responsive design

✅ Add database support for:

list visibility, ranked, items, tags, shared_to, reaction_count, save_count

✅ Ensure actions respect permissions (only creators can edit/unshare)

✅ Do not regress any feed or search performance
