ARIA & Accessibility

FAB: aria-haspopup="menu", aria-expanded={isPopoverOpen}

Popover: role="menu", each item role="menuitem"

Trap focus within the popover; close on Escape or outside click

Ensure all buttons have aria-label or visible text

Behavior

openPhotoPost opens your Photo/Post modal

openFoodMoment opens the Food Moment flow

openListBuilder opens the List Starter canvas

Clicking outside or pressing Esc closes the popover

Styling

Tailwind: fixed bottom-6 right-4, bg-primary, shadow-lg, rounded-full, text-white

Popover: bg-white, shadow-md, rounded-lg, p-2, text-sm font-medium

Menu items: hover:bg-gray-100, min-h-[44px], gap-2

🧪 Test Cases
 FAB appears on HomePage and FeedPage only

 Popover opens/closes reliably (click, outside click, Esc)

 Each menu item triggers the correct modal or route

 Keyboard navigation works (Tab into FAB, navigate menu, Esc closes)

 Tap targets ≥ 44px, ARIA attributes present

This ensures the “+” button gives users a consistent entry point to create content on both home and feed, matching modern best practices.
